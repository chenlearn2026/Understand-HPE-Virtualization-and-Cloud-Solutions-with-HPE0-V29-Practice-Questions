## Know the exam you are preparing for

The intended candidate has foundational knowledge of public, private, and hybrid cloud delivery models. HPE also expects an understanding of how flexibility, control, cost, and compliance relate to workload requirements.

Verified examination details include:

- Delivery type: proctored.
- Duration: 90 minutes.
- Length: 40 questions.
- Passing score: 65%.
- Language: English.
- Reference material: not allowed at the testing site.

HPE recommends the HPE ATP - Virtualization and cloud solutions modular curriculum through HPE Tech Pro. Check the complete requirements of any certification you intend to earn rather than assuming that one exam establishes the entire credential.

## Start with cloud foundations and GreenLake

GreenLake, HPE Services, and Cloud Fundamentals accounts for 12%. Review cloud and virtualization concepts, common container use cases, digital sovereignty, GreenLake architecture, partner benefits, and the HPE Services portfolio.

For a learning exercise, describe a hypothetical workload requirement and the questions it raises about control or compliance. Use those questions to guide reading without assuming the requirement always leads to the same product.

## Compare the private cloud offerings carefully

HPE Private Cloud Business Edition contributes 13%. Its scope includes building blocks, setup, network topology, deployment architecture, Single Click Update, Active Peer Persistence support, and management.

HPE Private Cloud Enterprise represents 12%. Study its managed service framework, workloads, building blocks, support, and competition.

HPE Private Cloud AI adds 13%, covering capabilities, use cases, components, and alternative approaches. Organize notes around the different objectives instead of treating the three offerings as interchangeable private cloud labels.

## Separate the two Morpheus subjects

HPE Morpheus VM Essentials Software carries 12%. Candidates should summarize its positioning, describe the architecture, and identify competitive products.

HPE Morpheus Enterprise Software has a 13% weight. Its scope includes capabilities and architecture, installation and configuration, groups and clouds, roles and permissions, users and settings, provisioning, catalog items, the Service Catalog Persona, and monitoring.

The similar product names make careful explanations worthwhile. Write what the outline asks you to understand about each one before adding detailed study notes.

## Include protection and operations in the review

The HPE Zerto Software domain contributes 13%. It includes data protection terminology, replication and snapshots, recovery, backups, data classification, tape, Zerto positioning, licensing, and protection architectures.

The same domain covers immutable Cloud Vault recovery copies within MSP cloud infrastructure. Review protection, detection, recovery, and isolation as distinct requirements in the learning examples.

HPE OpsRamp Software represents the remaining 12%. Prepare to summarize the software and the key aspects of an OpsRamp solution. Avoid reducing this domain to product-name recognition.
